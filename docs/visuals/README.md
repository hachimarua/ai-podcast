## 図を追加するときの約束

1. ファイル名はAIが扱いやすい英小文字のkebab-caseにする。
2. 図中のタイトルと説明は、人が読みやすい日本語にする。
3. 各図に「何を判断する図か」と最終更新日を書く。
4. 採用した図だけをこの一覧へ追加し、会話中の試案は登録しない。
5. 実装変更で図が古くなった場合は、同じ変更内で更新する。
